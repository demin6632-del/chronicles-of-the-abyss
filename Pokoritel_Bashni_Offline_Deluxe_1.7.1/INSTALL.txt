Pokoritel Bashni Offline Deluxe 1.7.1

Установка:
1. Соберите APK через Android Studio или GitHub Actions.
2. Установите APK на Android-устройство.
3. Запустите игру.

Игра работает офлайн, интернет для игрового процесса не требуется.
Финальная сборка использует корневой game.html как единый источник игры.
Прогрессия: обычный забег → New Game+ → бесконечная Бездна.
